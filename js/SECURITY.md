# Security

This repository is an early tokenless reference implementation, not a secure
production release. Do not use it with private data, economic value, public
network exposure, or identities that must survive loss.

Report suspected vulnerabilities privately to the project maintainers. Do not
include secrets, private work, credentials, recovery material, or personal data
in an issue or test fixture.

Production claims remain blocked until the public Somavera acceptance gates,
independent implementations, cryptographic vectors, and external review pass.
