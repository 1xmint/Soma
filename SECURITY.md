# SECURITY POLICY

This repository is a draft specification and recovery toolkit. It does not contain a production network or valuable token.

Do not submit real private keys, mnemonics, recovery shards, tokens, private agent work, personal data, customer data, or proprietary datasets in issues, pull requests, test fixtures, or recovery capsules.

For a suspected vulnerability, prepare:

- affected release and artifact hash;
- minimal reproduction using test-only material;
- security impact and preconditions;
- suggested embargo duration if public disclosure would create immediate harm.

Until a public security contact and encryption key are ratified, do not place undisclosed production vulnerability details in this repository. Publish only a minimal notice that a private report channel is required. A mainnet release is blocked until SECURITY.md names at least two independent monitored contacts, a disclosure SLA, an encryption key, and an emergency process consistent with GOVERNANCE.md.

No contributor may claim that review, testing, or one audit makes the system bulletproof. Release notes must disclose known limitations.
